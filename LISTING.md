# KDE Store (`store.kde.org`) — Product Listings

## 1. App Drawer (`me.masterh.appdrawer`)

- **Name**: `App Drawer`
- **Category**: `Plasma 6 Applets`
- **License**: `GPL-3.0`
- **Version**: `1.1`
- **Source / Website**: `https://github.com/HmFlashy/plasma6-widgets/tree/main/applets/me.masterh.appdrawer`
- **Package file**: `me.masterh.appdrawer-1.1.plasmoid`

### Description
```markdown
A lightweight KDE Plasma 6 panel widget that groups applications, folders, and web links into a compact taskbar icon with a live 2×2 or 3×3 mini-icon preview.

### Features
- Live 2×2 or 3×3 mini-icon preview directly in the taskbar
- Smooth hover & drag-over animations on the panel icon and mini-icons
- Drag & drop support for `.desktop` apps, Kickoff menu items (`applications:...`), folders, and URLs
- Pin button to keep the popup open while launching multiple apps
- Right-click context menu & internal drag-and-drop to reorder or remove items
- Configurable columns, icon size, preview grid (`2×2` / `3×3`), and custom popup dimensions
- Built-in searchable app picker + custom URL/command entry
```

## 2. NVIDIA GPU Monitor (`me.masterh.gpumonitor`)

- **Name**: `NVIDIA GPU Monitor`
- **Category**: `Plasma 6 Applets`
- **License**: `GPL-3.0`
- **Version**: `1.0`
- **Source / Website**: `https://masterh.me` (`https://github.com/HmFlashy/plasma6-widgets`)
- **Package file**: `me.masterh.gpumonitor-1.0.plasmoid`

### Description
```markdown
Lightweight KDE Plasma 6 panel/desktop monitor that displays NVIDIA GPU utilization, temperature, clock speed, VRAM, and power draw only when the GPU is active (`D0`), auto-detecting the NVIDIA PCI device and GPU name while preserving `D3cold` sleep on hybrid laptops.
```
